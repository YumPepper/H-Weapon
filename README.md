              H 武器 — 硬件检测 & 温度监测工具  v1.0.0
═══════════════════════════════════════════════════════════

【简介】
  H武器 是一款纯 Go 语言编写的 Windows 原生桌面硬件检测与
  温度监测工具。它以 Win32 原生窗口呈现图形化仪表盘，无需
  浏览器、无需安装运行时，双击即可运行。

【文件清单】
  Computer-H.exe   主程序（双击运行）
  config.json      配置文件（温度阈值 / 刷新频率）
  README.txt       本说明文档
  src\             源代码目录（.go 源文件）
    ├─ main.go       程序入口
    ├─ win32.go      Win32 窗口注册与消息循环
    ├─ gui.go        窗口过程 + GDI 仪表盘绘制
    ├─ hardware.go   CPU/GPU/内存/磁盘/主机采集
    ├─ monitor.go    温度监测与状态分级
    ├─ config.go     配置加载
    ├─ go.mod / go.sum  依赖描述

【运行环境】
  Windows 7 / 8 / 10 / 11（64 位）
  无需安装，绿色单文件 + 配置

【使用方法】
  1. 将本文件夹完整解压到任意目录
  2. 双击 Computer-H.exe 启动
  3. 窗口自动显示各项硬件信息，并按设定间隔刷新
  4. 关闭窗口即退出程序

【监测项目】
  · CPU：名称、核心数、使用率、温度
  · GPU：名称、驱动、显存、使用率、风扇、功耗、温度
  · 内存：总量/已用/可用、使用率进度条
  · 磁盘：分区、容量、使用率
  · 主机：操作系统、内核、主机名、运行时长

【温度标准 — GPU（按需求设定）】
  ┌──────────┬───────────┬──────────────┐
  │ < 30 °C  │   过冷    │   冰蓝       │
  │ 30~80 °C │   正常    │   翠绿       │
  │ 80~90 °C │   较热    │   琥珀       │
  │ > 90 °C  │   过热    │   赤红       │
  └──────────┴───────────┴──────────────┘

【温度标准 — CPU（可在 config.json 调整）】
  ┌──────────┬───────────┐
  │ < 20 °C  │   过冷    │
  │ 20~75 °C │   正常    │
  │ 75~85 °C │   较热    │
  │ > 85 °C  │   过热    │
  └──────────┴───────────┘

【配置说明 — config.json】
  {
    "cpu": { "cold": 20, "normal": 75, "warm": 85 },
    "gpu": { "cold": 30, "normal": 80, "warm": 90 },
    "refresh_seconds": 2,   // 数据刷新间隔（秒）
    "port": 9527            // 预留端口字段
  }
  修改后重启程序生效。
  若删除 config.json，程序会自动生成默认配置。

【GPU 温度读取说明】
  GPU 数据通过 nvidia-smi 采集（NVIDIA 显卡）。
  若为非 NVIDIA 显卡或未安装驱动，将显示"未检测到独立 GPU"。
